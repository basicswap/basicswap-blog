# basicswap-blog

The BasicSwap blog moved to [basicswapdex.com/blog](https://basicswapdex.com/blog). Its posts now live in the [basicswapdex.com repository](https://github.com/basicswap/basicswapdex.com), under `src/content/blog`.

This repository serves `blog.basicswapdex.com`, where every old address forwards to its own post or tag page on the new site, and old image addresses keep working. The `site/` folder is that redirect site, and `.github/workflows/deploy.yml` publishes it to GitHub Pages. It is generated by `tools/blog-redirects.mjs` in the basicswapdex.com repository, so to change a redirect, edit the script there, regenerate the site and replace `site/` with the output.

The blog as it was before the move is on the [`legacy`](https://github.com/basicswap/basicswap-blog/tree/legacy) branch.
